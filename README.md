# private-video-compressor

A 100% privacy-first, client-side video and audio compressor and converter powered by **FFmpeg.wasm**. 

## ✨ Features

* **Zero Server Uploads:** All compression and conversion happen directly inside your browser using WebAssembly. Your files never leave your device!
* **Lightning Fast:** High-performance processing with smart multi-thread and single-thread fallbacks.
* **No Installation Required:** Works seamlessly on any modern web browser.
* **Privacy Focused:** Complete data security since processing is local.

## 🛠️ Tech Stack

* HTML5 & Vanilla JavaScript
* Tailwind CSS / Custom Styling
* FFmpeg.wasm (WebAssembly)

## 🚀 How to Use

1. Open the live web app.
2. Drag and drop or select your video/audio file.
3. Click on **Compress / Convert**.
4. Download your optimized file instantly!
